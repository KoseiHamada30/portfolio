| 2026-11-01 | **Splash plays on every full load / refresh of the home page** (was once per session). In-site navigation to Work (from /info, a case study, the nav) never plays it: the inline script only adds `html.splash-on` while `document.readyState === 'loading'`, which is true for real loads and false when ClientRouter swaps the page in. `sessionStorage.splash-seen` removed; test suites opt out with `window.__splashBooted`. | 2026-11-01 | Splash (4R-a) rhythm follows the live reference, not the update doc's "letter roll on entrance": fade in → counter → 300ms hold → right-to-left letter roll (900ms expo.out, 50ms stagger) → exit. | 2026-11-01 | Splash background is `--paper-200` and the rising sheet is `--sheet` (`--paper-100`). | With identical colours the sheet would be invisible; the reference also uses a lighter sheet over a slightly darker splash. |
| 2026-11-01 | The splash is an overlay in a new `overlay` slot at the start of `<body>`.
