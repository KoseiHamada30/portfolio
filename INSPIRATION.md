# INSPIRATION.md — Reference board

> How to use: open each link, and when something clicks, **screenshot or screen-record it** into
> `references/` in the project (e.g. `references/03-list-hover-preview.png`). Claude Code can see images,
> and "make it feel like this screenshot" works far better than describing it in words.
> Copy *patterns*, never layouts, copy or branding.
